# Mobility Requirements Specifications

Version-controlled Mobility Requirements Specifications live here. This area
does not accept legacy prototype inputs.

Each specification is a Markdown file. Its YAML front matter holds only what
code reads: `schema_version`, `document_version` and the unique
`requirement_ids`. The body is the specification itself, in the usual
requirements-document order, and is read by people and the composition model.
The front matter is checked by `integration/schemas/mobility-requirements-specification-v1.schema.json`.

The S-04 specification plans verification; it does not claim that
verification occurred.
